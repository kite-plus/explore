> Explore is in planning. There is no code here yet.

Explore is the discovery side of [Kite Plus](https://github.com/kite-plus). [Kite](https://github.com/kite-plus/kite) helps people write and publish from files they own; Explore will gather what they publish and help readers find it.

## Status

Explore is being planned. Design notes and code will land in this repository as the work starts.

## Get involved

Have an idea about how discovery should work? [Open an issue](https://github.com/kite-plus/explore/issues) to start the conversation.
